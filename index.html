// Best practices

📏
Length beats complexity
A 20-character lowercase passphrase is harder to crack than an 8-character complex password. Every extra character multiplies the search space.
🎲
Use a passphrase
Four random words strung together (e.g. "correct-horse-battery-staple") are both memorable and extremely high-entropy.
🔐
Use a password manager
Tools like Bitwarden, 1Password, or KeePass let you use a unique, strong password for every site without memorizing any of them.
🚫
Never reuse passwords
A breach on one site instantly compromises every account sharing that password. One site, one password — no exceptions.
